# DevOps Collaborative

A full-stack incident management and alerting dashboard.

## 🚀 Live Environment

- **Frontend Application**: [https://dev-ops-collabrative-frontend1.onrender.com/](https://dev-ops-collabrative-frontend1.onrender.com/)

## 🛠 Tech Stack

- **Frontend**: React, TanStack Start, Vite, TailwindCSS
- **Backend**: Node.js, Express, TypeScript, Prisma (PostgreSQL)
- **Deployment**: Render (Web Services)
